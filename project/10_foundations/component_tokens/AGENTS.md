# Component token 局部規則

- 本層疊加 Foundations 規則。
- 每個元件 family 使用一檔。
- 新檔延續 `noN` 編號。
- 所有值引用 atomic 階梯。
- 禁止直接使用 raw number。
- 視覺校準必須標註原因。
- 檔尾統一 export 到 `window`。

## Visualizer 配對

- token 與 visualizer 一對一。
- 兩側使用相同編號與名稱。
- key 變動同步描述與來源。
- 本層在 atomic 之後載入。
- 本層在消費端之前載入。

## 指令檔維護

- `AGENTS.md` 是本層真相。
- `CLAUDE.md` 僅保留相容入口。
